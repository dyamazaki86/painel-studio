# Painel Studio

Editor visual 2D para dimensionar painéis de automação e distribuir componentes usando as medidas da biblioteca.

## Como abrir

Baixe os arquivos `index.html` e `painel-studio.js` mantendo-os na mesma pasta e abra `index.html` em um navegador moderno.

## Recursos do protótipo

- Biblioteca de componentes com dimensões configuráveis e imagens.
- Montagem por arrastar e soltar em um painel com unidades em milímetros.
- Trilhos DIN com snap e canaletas com comprimento ajustável.
- Propriedades, zoom, navegação, réguas e exportação PNG.
- Arquivamento local de projetos no navegador.

Este protótipo é visual. Regras de dimensionamento e validações elétricas podem ser adicionadas em etapas futuras.
