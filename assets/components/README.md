Coloque nesta pasta as imagens dos componentes (PNG, JPG, SVG ou WebP).

Ao enviar uma imagem pelo editor, selecione a pasta raiz do projeto na primeira solicitação do navegador. O editor criará `assets/components/`, gravará o arquivo e associará o caminho ao componente. Mantenha essa pasta junto de `editor.html`, `painel-studio.js` e `components/` ao copiar ou publicar o projeto.
