# Catálogo de componentes

A biblioteca padrão de fallback fica definida em `catalog.js`. No editor online, o catálogo compartilhado é carregado do Supabase e pode ser administrado por contas com o cargo `admin`.

Para alterar o catálogo de fallback usado sem o Supabase, acrescente objetos ao array `window.PANEL_STUDIO_COMPONENTS` com dimensões em milímetros. As canaletas ficam em `window.PANEL_STUDIO_CHANNEL_PROFILES`. Na biblioteca online, admins criam e ordenam categorias e subcategorias, além de cadastrar componentes com imagens compartilhadas.
