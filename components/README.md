# Catálogo de componentes

A biblioteca padrão é definida em `catalog.js` e carregada pelo `editor.html`.

Para incluir componentes, acrescente objetos ao array `window.PANEL_STUDIO_COMPONENTS` com dimensões em milímetros. As canaletas ficam em `window.PANEL_STUDIO_CHANNEL_PROFILES`. Uma imagem já existente pode ser associada diretamente com o campo `image` usando um caminho relativo a partir da raiz do projeto.
